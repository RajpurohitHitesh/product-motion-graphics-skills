Access states have different meanings:

- **Metadata only:** title/duration/description; no visual style verification.
- **Poster only:** a static promotional image; cannot establish a video sequence.
- **Storyboard reviewed:** actual ordered source samples; supports visible layouts and coarse shot concepts, with resolution and timing limits.
- **Playback reviewed:** continuous motion inspected for the stated sections.
- **Audio reviewed:** audio actually heard for the stated sections; separate from visual review.

Do not upgrade an access state without doing the corresponding review. Saved evidence is for reference analysis, not a licensed product-media library or final-video footage.
