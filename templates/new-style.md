# New product style template

Copy this template into a new `styles/<descriptive-kebab-case-id>/STYLE.md` when a reviewed reference or an explicit owner design request justifies a distinct, useful style. For an owner-requested hybrid, identify the contributing style guides and the new purpose; do not invent new reference observations. Replace the guidance below with actual instructions and append a row to the style menu. This is a style inside the product skill, not another skill entry point.

## Identity and product fit

Give the style a clear name, a short visual description, and the types of product stories/assets that suit it. Explain how it differs from the closest existing style. Avoid creating a duplicate for a new accent color or a single transition.

## Visual system

Define palette logic, typography hierarchy, product framing, layout, material/lighting treatment, and caption placement for 1080 × 1920. Treat source palettes and observed values as evidence; mark inferred values as starting suggestions.

## Motion grammar

Describe recurring movement, easing, entrances, holds, transitions, and rhythm. Use seconds or frame counts with an explicit fps. Distinguish observed reference timing from proposed production settings.

## Product story

Describe an adaptable hook → product → benefits → payoff → CTA flow. Keep claims tied to the user's product. Explain how images, clips, screenshots, or mixed assets can express this style.

## Female voice and sound

Describe natural female delivery, pacing, pause/emphasis behavior, and music relationship. Retain the main skill's distinction between real recordings and synthetic voices and its pending-audio behavior.

## Preview and quality checks

Specify which short sequence best demonstrates the style after user selection. State concrete checks for product accuracy, phone readability, narration, and style-specific failure cases.

## Learned references

Link to actual evidence notes in this style's `references/` subfolder. Include only inspected sources and preserve their limitations. The folder and notes should be created when there is real evidence, not as empty scaffolding.
