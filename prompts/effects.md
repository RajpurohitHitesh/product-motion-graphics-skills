# 20 product-motion effect prompts

Use one effect when it helps the current selected style and actual assets. These are prompt helpers, not a new style or an effect pack. New videos still need style confirmation before a visual preview. Keep real UI, data, product identity, voice timing and readable holds intact. Do not add all 20 effects to one video.

## 1. Screenshot focus zoom

```text
Create a controlled focus zoom on the relevant feature in the supplied screenshot,
using the selected style. Preserve its aspect ratio and readable detail. End with enough
context for viewers to understand the feature's location in the app.
```

## 2. Spotlight highlight

```text
Highlight the actual target in the screenshot with a subtle outline or spotlight.
Keep the surrounding context readable and the highlight aligned during crop and scale changes.
```

## 3. Explanatory callout

```text
Animate one concise, separate callout explaining the visible feature. Keep it distinct
from the real UI, connect it to the actual target, and avoid covering the captions.
```

## 4. Accurate tap cue

```text
Show a short tap cue on the actual control for a verified tutorial action. Follow it
only with an evidenced next screen or result; do not invent missing interactions or success states.
```

## 5. Floating feature card

```text
Present the actual UI crop as a separate card with subtle lift, shadow, and depth.
Keep feature text sharp and readable without generating new controls or labels inside the screenshot.
```

## 6. Phone fan / card stack

```text
Introduce the supplied screens in a fan or stacked layout, then settle on one readable
hero screen. Keep supporting screens secondary so tilt and tiny text do not compete for attention.
```

## 7. Staggered headline reveal

```text
Reveal the approved headline in short, staggered phrase groups. Follow the reading
order, natural female narration, and selected style's pace. Break up dense text.
```

## 8. Kinetic keyword emphasis

```text
Emphasize one important keyword in the approved spoken line using scale or position.
Time it to an actual speech accent or an available, heard musical accent while preserving readability.
```

## 9. Product match cut

```text
Create a match cut anchored to a common shape or position in two actual product assets.
Preserve source identity and proportions; do not generate an unseen product angle to bridge the cut.
```

## 10. Masked feature transition

```text
Introduce the next verified feature screen with a simple mask or wipe compatible with
the selected style. Orient the viewer and hold meaningful UI labels long enough to read.
```

## 11. Bounded screenshot pan

```text
Create a controlled vertical pan over available content in a tall screenshot. Stay
within the actual image bounds and identify it as presentation motion rather than verified app interaction footage.
```

## 12. Chart path reveal

```text
Reveal a chart path from the supplied exact data. Preserve axes, time ranges, units,
and final values. For a screenshot-only source, mask or reveal the real chart instead of redrawing guessed points.
```

## 13. Metric count-up

```text
Animate a count-up to the owner's supplied exact metric, preserving the final number,
unit, and source label. Do not present intermediate animation values as measured time-series data.
```

## 14. Layered depth / parallax

```text
Add depth through subtle relative movement of available product or UI layers. Keep
main information stable and readable. Do not claim unseen geometry or an accurate 3D model from one flat asset.
```

## 15. Product light accent

```text
Add a restrained moving light accent to the background or overlay in the selected
cinematic direction. Preserve actual source detail, product material, packaging color, and printed labels.
```

## 16. CTA emphasis

```text
Give the supplied CTA one gentle emphasis or pulse, followed by a readable hold.
Preserve brand and caption space. Do not invent app buttons, store badges, discounts, or action results.
```

## 17. Real field typing

```text
Animate the verified search or target-price input inside its actual field. Focus it,
show a caret, type the intended value character by character, and pause before the
supported submit action. Preserve border, padding, icon and final captured value.
Use quiet key sounds only while characters appear. Show a preset selection as a tap.
```

## 18. One marked keyword

```text
Mark one important word in this approved phrase with a highlighter swipe for an
energetic Creator treatment, or a restrained accent pill for Clean Tech. Keep the
text readable throughout, align the landing to its spoken word when available,
and retain a recognizable product anchor. Match the current style's energy.
```

## 19. Shared picture and sound events

```text
Drive the focus move, actual tap, typing interval, result state and their sounds
from one event map. Use a lighter mix under supplied narration; leave speech empty
when voiceover comes later. Avoid duplicate effects when seeking and keep the
finished result still long enough to read. Mark unaligned draft timing as provisional.
```

## 20. Cover-ready product frame

```text
Compose a settled frame in the current style with one actual product/feature hero,
a short truthful hook and at most one supporting callout. Check it at phone-preview
size and within a centered square crop. Reuse the same assets and scene components.
Export a separate thumbnail only if requested; no second full-video render is needed.
```

Use [the selected style guide](../styles/INDEX.md), [screenshot rules](../references/screenshot-videos.md), [motion craft](../references/motion-craft.md) and [production rules](../references/production.md) to decide which effect fits. The actual preview/source files must exist before reporting an effect implemented or validated.
