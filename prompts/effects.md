# 16 product-motion effect prompts

Use one effect when it helps the current selected style and actual assets. These are original prompt helpers, not a new style or an effect pack. New videos still need style confirmation before a visual preview. Keep real UI, data, product identity, voice timing and readable holds intact. Do not add all 16 effects to one video.

## 1. Screenshot focus zoom

```text
Selected style mein supplied screenshot ke relevant feature par controlled focus zoom
banao. Original aspect ratio aur readable detail preserve karo; scene ke end mein enough
context dikhao ki viewer ko app mein location samajh aaye.
```

## 2. Spotlight highlight

```text
Screenshot ke actual target ko subtle outline/spotlight se highlight karo. Background
context readable rahe, aur crop/scale ke saath highlight usi target se aligned rahe.
```

## 3. Explanatory callout

```text
Visible feature ke liye ek concise separate callout label animate karo. Label explanation
ho, real UI ka replacement nahi; connector actual target se linked rahe aur captions ko cover na kare.
```

## 4. Accurate tap cue

```text
Verified tutorial action ke actual control par short tap cue dikhao. Uske baad sirf
evidenced next screen/result show karo; missing interaction ya success state invent mat karo.
```

## 5. Floating feature card

```text
Actual UI crop ko separate presentation card ki tarah subtle lift, shadow aur depth do.
Feature text sharp/readable rahe; screenshot mein naye controls ya labels generate mat karo.
```

## 6. Phone fan / card stack

```text
Supplied screens ko fan ya stacked layout mein introduce karo, phir ek readable hero
screen par settle karo. Saari screens ko ek saath tilt aur tiny text ke saath compete mat karwao.
```

## 7. Staggered headline reveal

```text
Approved headline ko short phrase groups mein stagger karke reveal karo. Reading order,
natural female narration aur selected style ka pace follow karo; dense text ko break karo.
```

## 8. Kinetic keyword emphasis

```text
Approved spoken line ke ek important keyword ko scale/position emphasis do. Actual
speech accent, ya available heard music accent, ke saath time karo; readability preserve karo.
```

## 9. Product match cut

```text
Do actual product assets ke common shape/position ko anchor bana kar match cut banao.
Source identity aur proportions preserve karo; unseen product angle generate karke bridge mat banao.
```

## 10. Masked feature transition

```text
Selected style se compatible simple mask/wipe se next verified feature screen introduce
karo. Viewer ko orientation mile aur meaningful UI labels transition ke baad readable hold mein dikhein.
```

## 11. Bounded screenshot pan

```text
Tall screenshot ke available content par controlled vertical pan banao. Actual file bounds
ke andar raho; is presentation move ko real app interaction ka verified recording mat bolo.
```

## 12. Chart path reveal

```text
Supplied exact chart data se path reveal banao. Axes, time range, units aur final values
preserve karo. Screenshot-only source ho to real chart ko mask/reveal karo; guessed points se redraw mat karo.
```

## 13. Metric count-up

```text
Owner-supplied exact metric ko clearly animated count-up treatment do; final number,
unit aur source label accurate rahe. Intermediate animation ko real measured time-series data mat dikhao.
```

## 14. Layered depth / parallax

```text
Available product/UI layers ko subtle relative movement se depth do. Main information
stable aur readable rahe; single flat asset se unseen geometry ya accurate 3D model claim mat karo.
```

## 15. Product light accent

```text
Selected cinematic direction mein background/overlay par restrained moving light accent
do. Real product material, packaging color aur printed labels alter mat karo; actual source detail preserve karo.
```

## 16. CTA emphasis

```text
Supplied CTA ko ek gentle emphasis/pulse ke baad readable hold do. Brand aur caption
space preserve karo; nonexistent app button, store badge, discount ya action result invent mat karo.
```

Use [the selected style guide](../styles/INDEX.md), [screenshot rules](../references/screenshot-videos.md) and [production rules](../references/production.md) to decide which effect fits. The actual preview/source files must exist before reporting an effect implemented or validated.
