# Brand design system

Use when setting up reusable context for a product, or when the user explicitly wants brand preferences updated. The files belong to the output project.

## Set up once, reuse across styles

```text
Set up reusable product brand context using the Product Motion Graphics skill's brand-setup mode.
Inspect existing project instructions, brand.md, MOTION.md, and supplied assets first.
Reuse details already provided. Clarify only missing essential information.

In the output project's brand.md, save or update the product, audience, supported benefits
with sources, tone, CTA, and actual asset paths.
In MOTION.md, record supplied colors and fonts, logo treatment, layout, motion preferences,
female voice and language preferences, captions, and output defaults.
Mark unknown tokens and unverified claims as pending. Do not guess exact brand specifications
from visual references. Preserve useful existing content.

Every style should read these profiles, but ask me to confirm the style for each new video.
This request is for brand setup only; do not generate a video preview.
Finish by listing the saved files and unresolved details.
```

Available inputs: logo, real UI/product assets, exact color codes if known, typeface guidance, supported features, audience, tone, CTA, voice recording/preferences, and approved brand references. Setup can begin without every field; identify any required gaps clearly.

## Optional read-first integration

```text
Provide the brand-setup guide's scoped read-first snippet so future product-video work
can discover the brand context. Use my project's actual file locations and explain how
the snippet fits the existing instructions.
```

The actual snippet and integration rules are in [brand setup](../references/brand-setup.md). Setup does not create a default style selection or silently modify other projects' instructions.

## Update an established brand preference

```text
Treat these supplied logos and colors as reusable brand preferences from now on.
Reconcile and update the output project's brand.md and MOTION.md. Preserve the actual
UI in product screenshots and retain existing verified claims. Summarize the changed preferences.
```
