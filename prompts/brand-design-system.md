# Brand design system

Use when setting up reusable context for a product, or when the user explicitly wants brand preferences updated. The files belong to the output project.

## Set up once, reuse across styles

```text
Product Motion Graphics skill ke brand-setup mode se meri product brand context set up karo.
Existing project instructions, brand.md, MOTION.md aur supplied assets pehle inspect karo.
Already provided details dobara mat puchho. Missing essential information hi clarify karo.

Output project mein brand.md mein product, audience, supported benefits with sources,
tone, CTA aur actual asset paths save/update karo.
MOTION.md mein supplied colors/fonts, logo treatment, layout, motion preferences,
female voice/language, captions aur output defaults record karo.
Unknown tokens aur unverified claims pending rakho; visual references se exact brand
specifications guess mat karo. Existing useful content preserve karo.

Har style in profiles ko read kare, lekin har naye video ke liye style mujhse confirm ho.
Abhi brand setup chahiye; video preview generate nahi karna.
End mein saved files aur unresolved details batao.
```

Available inputs: logo, real UI/product assets, exact color codes if known, typeface guidance, supported features, audience, tone, CTA, voice recording/preferences, and approved brand references. Sab fields ke bina setup start ho sakta hai; required gaps clearly mark honge.

## Optional read-first integration

```text
Brand context ko future product-video work mein discoverable rakhne ke liye
brand-setup guide ka scoped read-first snippet do. Mere project ke actual file
locations use karo aur existing instructions ke saath kaise fit hoga batao.
```

The actual snippet and integration rules are in [brand setup](../references/brand-setup.md). Setup does not create a default style selection or silently modify other projects' instructions.

## Update an established brand preference

```text
Ye supplied logo/colors ab se reusable brand preference hain. Output project's
brand.md aur MOTION.md ko reconcile karke update karo. Product screenshots ka actual
UI preserve karo aur existing verified claims retain karo. Changed preferences summarize karo.
```
